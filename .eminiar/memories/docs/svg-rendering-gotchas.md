clankmon's README images are generated by `cargo run --release --example docs` (examples/docs.rs) using src/ui/svg.rs. Gotchas found while building it (2026-10-21): (1) WebKit collapses repeated spaces in SVG <text> even with xml:space="preserve", which made textLength-stretched runs look wide; text runs are split at gaps of 2+ spaces and single spaces become U+00A0. (2) Block/braille/box glyphs must be vector shapes, not font glyphs, or rows show gaps. (3) Animated SVG size: emit only changed column spans per frame (changed_spans) and 1-decimal coordinates; demo.svg went 949 KB -> 236 KB. (4) In Rust raw strings, a literal `"#` (e.g. fill="#000") ends r#"..."#; use r##"..."##. (5) Preview locally with `qlmanage -t -s 1400 -o DIR file.svg` then downscale with sips to <~200 KB JPEG (the Read hook blocks larger images); thumbnails are square-cropped. Avoid emoji like ⚡ in the UI: double-width and emoji-coloured; use ↯/ϟ.
