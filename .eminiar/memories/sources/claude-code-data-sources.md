Claude Code (v2.1.292, macOS) exposes monitoring data in these places; clankmon reads them in this priority order.

1. Transcripts `~/.claude/projects/<slug>/<sessionId>.jsonl`, one JSON object per line. `type: assistant` lines carry `message.usage` {input_tokens, cache_creation_input_tokens, cache_read_input_tokens, output_tokens, output_tokens_details.thinking_tokens, cache_creation.{ephemeral_5m_input_tokens, ephemeral_1h_input_tokens}, service_tier, server_tool_use}, `message.model`, `message.id`, `message.stop_reason`, plus top-level `requestId`, `sessionId`, `cwd`, `gitBranch`, `timestamp`, `version`, `isSidechain` (subagent), `effort`/`perTurnEffort`, `thinkingDurationMs`, `advisorModel`. Streaming writes several lines per message, so dedupe on (message.id, requestId). API errors are assistant lines with `isApiErrorMessage: true`, `apiErrorStatus`, and `quotaLimits` {status, resetsAt (epoch s), rateLimitType: five_hour|seven_day, overageStatus, overageDisabledReason, isUsingOverage}. `type: user` lines with `toolUseResult` are tool results. Other types: system, summary, progress, file-history-snapshot, etc.
2. Live process registry `~/.claude/sessions/<pid>.json` {pid, sessionId, cwd, startedAt (ms), name, kind, entrypoint, version, messagingSocketPath}. Verify liveness with kill(pid,0). `<pid>.<hash>.key` files are peer tokens; ignore.
3. Statusline push: settings.json `statusLine.command` receives JSON on stdin with `rate_limits.five_hour/seven_day.{used_percentage, resets_at}` (Pro/Max only, after first API response), `context_window.{used_percentage, context_window_size, current_usage}`, `cost.{total_cost_usd, total_duration_ms, total_api_duration_ms, total_lines_added, total_lines_removed}`, `prompt_cache.{warm, hit_ratio, misses, requests, expected_rebuilds, caching_observed}`, `model.{id, display_name}`, `effort.level`, `fast_mode`, `session_id`, `session_name`, `workspace`, `agent`, `worktree`. Debounced 300 ms; fires on assistant message, compact, mode change, rate-limit window change, and `refreshInterval`.
4. Hooks (settings.json `hooks`): SessionStart/SessionEnd/Stop/SubagentStart/SubagentStop/PreToolUse/PostToolUse/Notification/PreCompact/PostCompact/PostModelSwitch; input JSON has session_id, transcript_path, cwd, hook_event_name, tool_name, tool_use_id.
5. OpenTelemetry: CLAUDE_CODE_ENABLE_TELEMETRY=1, OTEL_METRICS_EXPORTER=otlp, OTEL_LOGS_EXPORTER=otlp, OTEL_EXPORTER_OTLP_PROTOCOL=http/json, OTEL_EXPORTER_OTLP_ENDPOINT=http://127.0.0.1:<port>, OTEL_METRIC_EXPORT_INTERVAL ms. Metrics claude_code.token.usage{type}, claude_code.cost.usage; events api_request {model, cost_usd, duration_ms, input_tokens, output_tokens, cache_read_tokens, cache_creation_tokens, request_id, query_source, effort, speed}, tool_result {tool_name, duration_ms, success}.
6. Proxy via ANTHROPIC_BASE_URL: every response from api.anthropic.com for OAuth requests (header anthropic-beta: oauth-2025-04-20) carries undocumented headers anthropic-ratelimit-unified-{5h,7d}-{utilization (0..1), reset (epoch s), status (active|warning|rate_limited)}, -unified-status, -unified-representative-claim, -unified-overage-status, -unified-fallback-percentage, -unified-reset, -unified-overage-disabled-reason. API-key requests carry documented anthropic-ratelimit-{requests,tokens,input-tokens,output-tokens}-{limit,remaining,reset} and retry-after.
7. OAuth usage endpoint GET https://api.anthropic.com/api/oauth/usage with Bearer accessToken (macOS Keychain generic password service "Claude Code-credentials", JSON {claudeAiOauth:{accessToken, refreshToken, expiresAt, scopes, subscriptionType, rateLimitTier}}; Linux fallback ~/.claude/.credentials.json) and anthropic-beta: oauth-2025-04-20. Returns five_hour/seven_day {utilization 0..100, resets_at ISO}, seven_day_opus/sonnet, extra_usage. Undocumented and 429s aggressively (anthropics/claude-code#31637): poll >= 10 min, back off, never refresh the token.
8. `~/.claude/stats-cache.json` {version, lastComputedDate, dailyActivity[{date, messageCount, sessionCount, toolCallCount}], dailyModelTokens[{date, tokensByModel}], modelUsage{model:{inputTokens, outputTokens, cacheReadInputTokens, cacheCreationInputTokens, webSearchRequests, costUSD}}}.
